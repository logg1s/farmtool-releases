# FarmTool releases

Bản phát hành Windows x64 và Android arm64/x64, changelog và SHA256.
Repo này chỉ chứa hướng dẫn và release assets; không chứa mã nguồn dự án hay dữ liệu tài khoản.

Tải từ [Releases](https://github.com/logg1s/farmtool-releases/releases/latest).
Windows: giải nén toàn bộ ZIP, chạy FarmTool.exe; cần Microsoft Edge WebView2.
Android: chọn APK đúng kiến trúc, cài đè cùng chứng thư, không gỡ app.

Ứng dụng tự kiểm tra release public, hiển thị changelog và kiểm tra SHA256 khi tải.
Windows thay toàn bộ thư mục chương trình sau khi thoát hẳn app; giữ dữ liệu LocalAppData/FarmTool.
Android yêu cầu người dùng xác nhận cài bằng trình cài đặt hệ thống.
Phiên bản tool độc lập với phiên bản luật game. Không chạy cùng tài khoản trên nhiều thiết bị.
