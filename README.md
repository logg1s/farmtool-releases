# FarmTool releases

Windows: tải duy nhất FarmTool-PC-Windows-x64.exe và chạy. Không cần giải nén hoặc _internal.
Cần Microsoft Edge WebView2 Runtime. Dữ liệu riêng vẫn ở LocalAppData/FarmTool.
Cập nhật: thoát hẳn app cũ ở khay hệ thống, rồi mở EXE mới.

Android: chọn APK arm64/x64 đúng kiến trúc, cài đè cùng chứng thư; không gỡ app.
App có kiểm tra bản mới, hiển thị/tải changelog và kiểm tra SHA256 khi tải file.

[Tải bản mới nhất](https://github.com/logg1s/farmtool-releases/releases/latest).

ZIP tương thích chỉ chứa một FarmTool.exe, phục vụ updater Windows 1.1.0/1.1.1.
Người dùng mới chỉ cần EXE. Không chạy cùng tài khoản trên nhiều thiết bị.

Repo này chỉ chứa hướng dẫn và release assets, không chứa source workspace hay dữ liệu tài khoản.
